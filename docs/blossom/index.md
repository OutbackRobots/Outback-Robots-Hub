# Blossom

This is the main page for the Blossom robot, which is used in the Outback Robots Program. You can find all the lessons and resources related to Blossom here.

Blossom is a low-cost open-source social robot designed for education. It was developed through a collaboration between Cornell University’s Human-Robot Collaboration and Companionship Lab and Google Creative Technologies Singapore.
All the documentation, including 3d printing files, build instructions, and code, are available on GitHub: [Blossom GitHub Repository](https://github.com/msgtn/r0b0/blob/main/docs/blsm.md).
